### 页面内容
```
[页面标题]
纯前端架构，零后端成本

[架构图]
┌──────────────────────────────────────────────────────┐
│  Layer 1: 用户界面 (React + Ant Design)              │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐        │
│  │简历优化│ │JD分析  │ │投递管理│ │面试准备│        │
│  └────────┘ └────────┘ └────────┘ └────────┘        │
└──────────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────────┐
│  Layer 2: AI服务层 (src/services/ai.ts)              │
│  ┌────────────────────────────────────────────────┐  │
│  │  策略模式：根据provider路由到不同实现          │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────────┐
│  Layer 3: AI提供商适配层                            │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐           │
│  │DashScope │ │ OpenAI   │ │ Claude   │ Custom      │
│  │ 阿里云   │ │          │ │          │ 中转       │
│  └──────────┘ └──────────┘ └──────────┘             │
└──────────────────────────────────────────────────────┘

[技术亮点1：多提供商支持]
• 支持DashScope、OpenAI、Claude、自定义接口
• 用户自主选择，不绑定单一服务商
• 通过中转服务解决CORS问题

[技术亮点2：JSON响应容错]
代码示例：
const jsonMatch = response.content.match(/\{[\s\S]*\}/);
if (jsonMatch) {
  return JSON.parse(jsonMatch[0]);
}
• 支持纯JSON、Markdown代码块包裹、多行JSON

[技术亮点3：隐私优先]
• API Key仅存储在浏览器LocalStorage
• 数据不上传任何服务器
• 用户完全掌控自己的数据
```

### 演讲词（50秒）
> "下面简单介绍一下技术架构。
> 
> 我们采用的是纯前端架构，零后端成本。整个系统分为三层：
> 
> 第一层是用户界面，用React+Ant Design开发，支持响应式布局。
> 
> 第二层是AI服务层，我们设计了一个统一的AI调用接口，根据用户选择的提供商，路由到不同的实现。这种设计模式叫"策略模式"，好处是新增提供商非常容易，只需要添加一个新的适配器。
> 
> 第三层是AI提供商适配层，目前支持四种：阿里云DashScope、OpenAI、Claude、以及自定义接口。
> 
> 这里有一个技术难点：CORS。浏览器直接调用OpenAI等海外API会遇到跨域限制。
> 
> 我们的解决方案是：推荐用户使用中转服务，比如OneAPI，它会把OpenAI的接口转换成兼容格式，并解决CORS问题。
> 
> 还有一个技术亮点是JSON响应容错。因为AI的输出不稳定，有时候会包裹在markdown代码块里，我们用了正则表达式提取，确保无论AI怎么返回，都能正确解析。"

## 附录：Q&A预案

### 常见问题准备

**Q1: 和超级简历有什么区别？**
> A: 超级简历主打简历模板和排版，用的是规则引擎；我们是真实AI分析，而且打通了从简历到投递的完整闭环。

**Q2: 怎么解决API成本问题？**
> A: 单次调用成本很低（2-8分钱），用户自备API Key，我们零成本运营。未来可以通过订阅制盈利。

**Q3: 纯前端架构安全性如何？**
> A: API Key存储在LocalStorage，虽然不如后端安全，但完全不上传服务器，用户可以完全掌控自己的数据。而且支持中转服务，可以隐藏真实Key。

**Q4: AI生成的内容会不会同质化？**
> A: 我们的Prompt设计包含了用户的简历具体信息，每次生成的内容都是个性化的，不是模板替换。

**Q5: 未来会商业化吗？**
> A: 短期开源免费积累用户，中期推出SaaS订阅版，长期对接企业端。
